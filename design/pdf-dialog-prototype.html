3.4 自注意力回顾

自注意力把序列里每个位置的表示，映射成 query、key、value 三组向量，然后用 query 与所有 key 的内积决定 value 的加权方式。它的代价是每层都要做一次全对全的比较，但好处是任意两个位置之间只隔一步，长距离依赖不再 需要沿着时间轴一格一格传递。

Attention(Q, K, V) = softmax(Q Kᵀ / √d) V

3.5 位置信息

这里有一个容易被忽略的性质：上面这个式子对输入顺序是不敏感的。把同一批 token 打乱之后再送进去，输出集合 不会改变，只是跟着一起换了位置。本节的模型既没有循环层， 也没有卷积层，因此顺序信息必须由外部显式补进来。

最直接的做法是在进入第一层之前，把一组与位置相关的向量加到词向量上，让后面所有层都能读到这份信息。这组 向量既可以用固定的函数算出来，也可以当作参数随训练一起更新。

本文采用前一种：用不同频率的正弦与余弦函数生成，维度与词向量一致，因此可以直接相加而不引入额外的融合层。 这样做的一个额外好处是，对训练时没见过的更长序列，函数式编码仍然能给出取值。

PE(pos, 2i) = sin(pos / 100002i/d)

后续工作沿着这条线走出了几个不同方向，有的把位置信息从输入端移到注意力计算内部，有的只保留相对距离而丢掉 绝对下标。这些取舍会直接影响模型能否外推到更长的上下文。
