# StepRead

最近做了个浏览器插件 StepRead，主要是想帮自己学习硬核书籍。Chrome 和 Edge 都能装。

它支持在浏览器里打开 PDF，边读边问 AI，并且可以把值得留下的问答手动整理成知识图谱。这样的学习流当然也可以在普通 AI 网站里完成，只是那里很容易把不同书、不同问题、不同任务混到同一个上下文里。StepRead 想解决的是一个更具体的问题：把提问、上下文、页码、划线和后续追问都留在当前 PDF 的阅读现场里。

它更适合结构精致的 PDF：有文字层、有目录、有比较稳定的段落和页码。没有 OCR 的扫描版 PDF 暂时不太行。出于自己的产品品味，我把用户能控制的参数基本都塞进设置页面了，大家可以下载体验一下。

## 核心功能

**阅读**

- 在浏览器中打开 PDF，并进入 StepRead 阅读器。
- 阅读器显示 PDF 正文、当前页码、目录/书签，并支持目录跳转。
- 左侧栏分「文档」和「目录」两个 tab；＋ 添加新文件，在 ＋ 或列表空白处右键可新建文件夹。

**提问**

- **划线提问**：选中一段正文再问，这段原文作为主要依据。
- **直接提问**：不划线也能问，此时问题针对整篇文档。
- 一份文档只有一条对话：不管划没划线，所有历史都在同一个对话框里。
- 可以回到过去任意一轮重新提问，从那里分出一条支线；右侧的路径栏显示当前走到哪，点「路径」可全屏展开对话路径图。
- 语音输入（用浏览器自带的语音识别，识别结果追加到输入框，不会覆盖已输入的字，也不会自动发送）。
- 可以清空这份文档的对话记录（两次点击确认，不影响已经加进知识图谱的切片）。

**联网查询**

- 打开后，每次提问会先让模型把「你的问题 + 文档主题 + 所在章节 + 划线原文 + 前两轮对话」提炼成检索词，再拿去搜，而不是把问题原样丢给搜索引擎。
- 支持 Tavily 和 Brave，用你自己的搜索 API key。
- 实际发出的检索词会显示在那一轮下面，来源可点，悬停能看到相关度分数 —— 搜得不准时你能直接看出是检索词的问题还是结果的问题。
- 模型判断这一问只关乎文档本身、网上不会有对应资料时，会直接说明并跳过检索，而不是硬塞几条不相干的结果。

**章节索引（长文档）**

- 在「目录」tab 里可以为整本书生成一份章节索引：每章一段摘要，一次生成、反复使用。
- 之后问整本书的问题时带这份索引，而不是把几十万字的正文塞进上下文。
- 划线提问和局部提问**不受影响**，仍然走逐字原文 —— 摘要是有损的，只适合回答全局问题。
- 生成前会告诉你要发多少次请求；逐章生成、可随时停止，已完成的部分会保留。正文重新导入后索引会标记为已过期。

**知识图谱**

- 切片由你手动收录：在阅读器里觉得某一轮值得留下，点「＋ 加入知识图谱」，它会出现在图谱页的「阅读证据」里，再拖到画布上。
- 默认**不自动连线**。连线由你自己拉，并标注关系；没想法时可以点魔法棒让 AI 给一个关系短语。
- 可以手动新建切片、编辑内容、删除切片，也可以从阅读证据里删掉某条问答记录。
- 右侧「图谱问答」可以直接对着整张图谱提问；每次打开时 AI 会用一句话概括这张图的状态。

**设置**

- 设置页分四块：基础 AI、AI context 接入、知识图谱、阅读器外观。
- 可调模型、接口地址、上下文范围、联网搜索、主题、划线样式、阅读器布局和交互参数。

## 适合什么 PDF

StepRead 依赖 PDF 的文字层和结构信息。推荐使用：

- 正版电子书、论文、报告、课程讲义等文字层清晰的 PDF。
- 有目录、标题层级、页码结构比较稳定的 PDF。
- 复制文字时不会严重乱码的 PDF。

暂时不推荐：

- 纯扫描图片 PDF。
- 没有 OCR 的影印版 PDF。
- 文字层顺序混乱、复制出来大量错位或乱码的 PDF。

## 本地安装方式

这是一个 Manifest V3 扩展，Chrome 和 Edge 都能本地加载。下载后不需要编译，直接把解压后的文件夹加载进去即可。

1. 下载本仓库。
   - GitHub 页面点击 `Code` -> `Download ZIP`。
   - 或者用 Git 克隆本仓库。
2. 解压到一个固定目录。
   - Windows 推荐：`D:\Tools\StepRead-extension`
   - 也可以放在：`C:\Users\<你的用户名>\Documents\StepRead-extension`
   - 不建议放在临时目录，也不要加载后随手删除或移动。浏览器加载的是这个目录本身。
3. 打开扩展管理页。
   - Chrome：地址栏输入 `chrome://extensions/`
   - Edge：地址栏输入 `edge://extensions/`
4. 打开“开发者模式”（Edge 里叫“开发人员模式”）。
5. 点击“加载已解压的扩展程序”（Edge 里叫“加载解压缩的扩展”）。
6. 选择刚才解压后的 StepRead 文件夹。
   - 这个文件夹的根目录里应该能看到 `manifest.json`。
   - 不要选择 `src` 文件夹。
   - 不要直接选择压缩包。
7. 加载完成后，可以把 StepRead 固定到浏览器工具栏。

以后更新时，把本地文件夹替换成新版本，然后回到扩展管理页，在 StepRead 卡片上点击“重新加载”。

## AI 配置

StepRead 使用你自己配置的模型接口，也就是 BYOK（Bring Your Own Key）。

1. 打开扩展管理页（`chrome://extensions/` 或 `edge://extensions/`）。
2. 找到 StepRead。
3. 点击“详细信息”或“扩展选项”，也可以在阅读器右上角点「设置」。
4. 在设置页填写参数，例如：
   - API Base URL、API Key、模型名称（OpenAI 兼容接口）
   - 上下文范围
   - 联网搜索：服务商（Tavily / Brave）、搜索 key、结果条数
   - 回答、知识图谱、划线和阅读器相关参数
5. 保存设置后再回到阅读器使用。

模型 key 和搜索 key 是两套独立的东西：联网搜索在 OpenAI 兼容协议里没有统一做法，所以走独立的服务和独立的 key，不配也不影响正常提问。

不要把自己的 API Key 写进代码、截图或提交到 GitHub。设置页保存的密钥只应该留在你自己的浏览器扩展存储里。

## 使用流程

1. 在浏览器中打开一个 PDF，点击 StepRead 扩展按钮把它送进阅读器；也可以在阅读器左侧栏点 ＋ 直接添加文件。
2. 提问，两种都行：
   - 选中一段正文再问 —— 这段原文作为主要依据；
   - 什么都不选直接问 —— 问题针对整篇文档。
3. 查看回答，继续追问。想换个方向时，回到过去某一轮重新提问，就从那里分出一条支线。
4. 点右侧的「路径」可以全屏看整棵对话树，点任意节点跳回那一轮。
5. 觉得某一轮值得留下，点回答下方的「＋ 加入知识图谱」。
6. 打开知识图谱页面，从左侧「阅读证据」把收录的问答拖到画布上。
7. 自己拉线并标注关系（没想法时点魔法棒让 AI 给一个短语）；双击空白新建手动切片。
8. 在右侧「图谱问答」直接对着整张图谱提问。

读长书时，先在「目录」tab 里生成一次章节索引，之后问整本书的问题会带上它。

如果某个 PDF 无法正确读取、目录跳转不稳定，通常原因是 PDF 自身的文字层、目录或页码结构不稳定。可以先测试一份文字层干净的 PDF，确认插件流程是否正常。

## 数据和隐私边界

- PDF 文件来自用户本地或浏览器当前打开的页面。
- 阅读记录、划线、问答和设置主要保存在浏览器扩展自己的本地存储中。
- 只有在你主动提问、生成回答或使用 AI 相关功能时，StepRead 才会把选中文本和必要上下文发送到你配置的 AI 服务。
- 联网查询默认关闭。打开之后，提问时会把提炼出的检索词发给你配置的搜索服务（Tavily 或 Brave）；实际发出的检索词会显示在那一轮下面。
- 生成章节索引会把各章正文分批发给你配置的模型，这一步只在你手动点「生成」时发生。
- 文档可以彻底删除：右键回收站里的条目选「彻底删除」，它的正文、划线、问答和图谱切片会一起从本地库里移除，不可恢复。
- 本仓库不包含我的本地 PDF、阅读记录、API Key 或本地路径。

## 常见问题

### 为什么扫描版 PDF 不好用？

StepRead 主要读取 PDF 的文字层。扫描版 PDF 的页面本质上是图片，如果没有 OCR 文字层，插件无法稳定知道你选中的文字是什么，也无法可靠建立页码、段落和目录关系。

### 为什么有些 PDF 目录跳转不准？

PDF 的目录项通常指向内部位置对象。不同 PDF 的目录、页码、坐标和文字层质量差异很大。StepRead 会尽量根据页码和标题位置修正，但低质量结构仍可能导致跳转偏移。

### 划线提问和直接提问有什么区别？

区别只在「主要依据」上。划线时，那段原文是回答的主要依据，周围段落和章节作为补充；不划线时，问题针对整篇文档。

两种提问都进同一条对话，历史不会因为切换而消失。

### 章节索引会不会让回答变糙？

会，所以它只用在一个地方：**不划线的整本书问题**。这类问题本来就答不了（几十万字塞不进上下文），有索引至少能答。

划线提问、局部提问永远走逐字原文，不碰索引 —— 你划出一句话问「作者这句到底什么意思」，能回答的只有那句话本身，摘要顶替不了。

### 联网查询搜回来的东西不相干怎么办？

先看那一轮下面显示的检索词。检索词不对，说明模型没抓住你想查的点，可以把问题问得更具体一些；检索词没问题但结果不行，多半是这个主题在公开资料里本来就没有对应内容 —— 未发表的文章、个人笔记都属于这种情况。

### 可以直接上传压缩包吗？

本地开发安装时不要选择压缩包。“加载已解压的扩展程序”需要选择解压后的文件夹，而且这个文件夹根目录必须包含 `manifest.json`。
